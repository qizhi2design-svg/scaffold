# PRDKit 产品使用指南

## 什么是 PRDKit？

PRDKit 是一个产品需求文档（PRD）和原型管理工具，帮助产品团队更高效地协作和沟通。

## 核心功能

### 1. 原型标注系统
- **可视化标注**：在原型页面上直接添加标注点，记录设计思路和交互说明
- **Markdown 支持**：使用 Markdown 格式编写详细的功能说明文档
- **实时预览**：修改标注内容后自动刷新，无需手动重载

### 2. 文件组织结构
```
workspace/
  └── prototypes/
      └── [原型名称]/
          ├── index.html    # 原型页面
          ├── script.js     # 交互脚本
          ├── style.css     # 样式文件
          └── marks/        # 标注文件夹
              └── mark-*.md # 标注文档
```

### 3. 快速开始

#### 创建新原型
1. 在 `workspace/prototypes/` 下创建新文件夹
2. 复制模板文件（index.html, script.js, style.css）
3. 根据需求修改页面内容

#### 添加标注
1. 在 HTML 元素上添加 `data-mark` 属性
2. 在 `marks/` 目录下创建 `mark-*.md` 文件
3. 使用 frontmatter 指定标注位置和关联元素

#### 启动预览服务
```bash
prdkit serve          # 生产模式
prdkit serve --dev    # 开发模式（支持热重载）
```

## 标注文件格式

```markdown
---
id: mark-unique-id
title: 标注标题
element: [data-mark="element-id"]
position: { x: 50%, y: 20% }
---

# 标注内容

使用 Markdown 格式编写详细说明...
```

## 最佳实践

1. **语义化命名**：使用有意义的 `data-mark` 属性值
2. **模块化组织**：将复杂页面拆分为多个组件
3. **详细标注**：记录设计意图、交互逻辑和技术实现要点
4. **版本管理**：使用 Git 管理原型和标注的版本变更

## 开发模式特性

- **文件监听**：自动检测文件变化
- **热重载**：修改后立即刷新浏览器
- **WebSocket 连接**：实时推送更新通知
- **彩色日志**：清晰展示文件变化和服务状态

## 技术栈

- **前端**：HTML5 + CSS3 + Vanilla JavaScript
- **构建工具**：Vite
- **服务器**：Node.js + Express + WebSocket
- **文件监听**：Chokidar
