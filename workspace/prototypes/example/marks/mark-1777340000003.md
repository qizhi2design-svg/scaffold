# 行动号召按钮（CTA）

## 设计原则
作为页面的主要行动点，按钮需要足够醒目并引导用户完成关键操作。

## 视觉设计
- **渐变背景**：紫色渐变与页面主题呼应
- **投影效果**：带有颜色的阴影增强立体感
- **悬停动画**：上浮 + 阴影加深，提供即时反馈

## 交互状态
1. **默认状态**：渐变背景 + 适度阴影
2. **悬停状态**：上浮 2px + 阴影加深
3. **点击状态**：回到原位，模拟按下效果

## 文案建议
- 使用动词开头：「开始使用」「立即体验」「免费试用」
- 保持简洁：2-4 个字最佳
- 传达价值：让用户明确点击后的收益

## 代码示例
```javascript
primaryButton.addEventListener('click', function() {
  // 处理按钮点击事件
  alert('按钮被点击了！');
});
```

## 可访问性
- 确保按钮有足够的点击区域（最小 44x44px）
- 提供清晰的焦点状态
- 支持键盘操作（Enter/Space）
